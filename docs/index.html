DOSe LED Control convierte el Ulanzi D200H en el panel de luz que tu lámpara nunca tuvo. Color, encendido y brillo a un dedo, sin abrir la app del móvil.

Cuatro teclas. Cero apps.

El plugin añade cuatro acciones al deck. Se configuran una vez y viven en tu perfil.

Acción Qué hace Pulsación larga

Color com.dose.ledcontrol.deck.color

La tecla es el color: pinta el tono elegido con su etiqueta y su hex. Un anillo marca la última aplicada.

Mantén: cicla la paleta global y guarda el color nuevo en esa tecla.

Power com.dose.ledcontrol.deck.power

Enciende y apaga. El estado real se refleja en la tecla, no en tu memoria.

—

Brightness com.dose.ledcontrol.deck.brightness

Nivel fijo, subir o bajar por pasos, o ciclo 25 → 50 → 75 → 100.

—

Settings & Status com.dose.ledcontrol.deck.settings

MAC, escaneo BLE, paleta y keep-alive. Verde conectado, ámbar buscando, rojo error.

Mantén: reinicia el puente BLE sin reiniciar Ulanzi Studio.

Se configura una vez

Paneles nativos de Ulanzi Studio. Nada de archivos de configuración a mano.

De cero a verde en cinco minutos

Necesitas Windows, Ulanzi Studio con el D200H conectado y Python con bleak.

  1. Prepara Python

    El puente BLE usa Python 3.10+ y la librería bleak. Una sola vez.

  2. Clona y despliega

    El deploy copia el plugin a Ulanzi Studio y conserva tus ajustes.

  3. Escanea y pulsa

    Reinicia Ulanzi Studio, arrastra Settings & Status, pulsa Scan, guarda y reconecta. Después, añade tus colores.

    Guía paso a paso
PowerShell 
# 1 · dependencia del puente BLE
PS> pip install bleak

# 2 · plugin
PS> git clone https://github.com/isDOSe/ulanzi-led-control.git
PS> cd ulanzi-led-control
PS> npm run setup
PS> npm run deploy

Lo que suele preguntarse

¿Necesito la app del fabricante?

Solo para el primer emparejamiento si tu lámpara lo pide. Después, cierra esa app: si mantiene la conexión, el PC no podrá hablar con la tira.

¿Por qué Python y no Bluetooth nativo?

Ulanzi Studio ejecuta plugins en Node y Windows no expone BLE de forma fiable desde ahí. bleak es el camino sin compilar módulos nativos. La idea es empaquetar el puente en 1.0 para que no haya que instalar Python.

¿Envía algo a internet?

No. El plugin no abre conexiones de red ni pide cuenta: habla con tu lámpara por Bluetooth LE y guarda ajustes y logs en su propia carpeta data/.

¿Funciona en macOS o con otro deck?

Está probado en Windows con el D200H. Cualquier deck de Ulanzi Studio debería servir; macOS usa la misma API de bleak, pero aún no está verificado.

¿Puedo cambiar el color desde el propio deck?

Sí. Mantén pulsada una tecla de color: avanza por la paleta global y guarda el color nuevo en esa tecla. La paleta se edita en Ajustes.
